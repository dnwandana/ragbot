# Share and export a conversation

<p class="lede">Send a conversation to someone who has no RAGBot account, or keep a copy outside the app. A share link shows a read-only snapshot. Export gives you a Markdown file or a PDF.</p>

## Create a share link

1. Open the conversation.
2. Click **Share** at the top right.
3. Click **Create link**.
4. Click **Copy** and send the link.

Anyone with the link can read the messages, charts, and sources in the conversation. They do not need an account. The page shows the workspace name, the date, and the message count, but no member names or ids.

::: info Who can share
Owners, admins, and editors hold the `conversation:share` permission by default. Viewers do not. A workspace admin can change this on the **Roles** page.
:::

## Update the snapshot

The link is a **snapshot**. New messages stay private until you update the link.

1. Click **Share**.
2. Click **Update snapshot**.

The link address does not change. Anyone who opens it sees the new messages.

## Revoke a link

1. Click **Share**.
2. Click **Revoke link**, then **Revoke**.

The link stops working at once. Anyone who opens it sees "This link is no longer available." You can create a new link later. The new link has a different address.

## Export as Markdown

Click **Export**, then **Markdown (.md)**. The browser downloads one file with the title, the date, every message, and a numbered source list under each answer. The file name comes from the conversation title.

## Export as PDF

Click **Export**, then **PDF (print)**. A new tab opens with a print view of the conversation, and the print dialog opens. Choose **Save as PDF** in the dialog. The print view uses the light theme and keeps each message on one page where possible.

## Privacy notes

- A share link is read-only. Visitors cannot send messages.
- Search engines are told not to index share pages.
- Anyone who has the link can open it. Treat the link like the content itself.
- The audit log records every share, update, and revoke.
